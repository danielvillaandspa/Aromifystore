# Aromifystore

متجر أجهزة التعطير بالعربية والعبرية والإنجليزية، يعمل كموقع ثابت دون خطوة بناء.

## التشغيل والفحص

يتطلب Node.js حديثًا، دون تثبيت حزم إضافية:

```sh
npm start
npm test
```

افتح `http://127.0.0.1:4173`. يلزم خادم عند المعاينة لأن JavaScript يستخدم ES modules.

## الملفات

- `index.html`: هيكل الصفحة.
- `assets/css/`: التصميم والعرض على الهاتف والخطوط.
- `assets/js/app.js`: التنقل واللغات والبحث والمعارض والتواصل.
- `assets/js/data/catalog.js`: المنتجات والصور والروائح.
- `assets/js/data/translations.js`: نصوص اللغات الثلاث والأسئلة الشائعة.
- `assets/js/data/config.js`: التواصل ومواعيد العروض وأسعار الباقات.
- `assets/js/offers.js`: منطق تفعيل العروض وانتهائها.
- `assets/images/products/`: صور المنتجات بأسماء وصفية.
- `assets/images/reference/`: صور موديلات إضافية تحتاج تأكيد هويتها.
- `assets/images/brand/`: الشعار الأصلي.
- `docs/image-map.json`: خريطة أسماء الصور الأصلية والجديدة.
- `docs/review.md`: التحقق والمعلومات التي تحتاج استكمالًا.

الصور بأسمائها الأصلية في جذر المستودع محفوظة أيضًا لضمان استمرار الروابط القديمة.

## تعديل العروض

تبدأ الباقات في 9 سبتمبر 2026 وتنتهي عند بداية 9 أكتوبر بتوقيت إسرائيل، أي إن آخر يوم كامل هو 8 أكتوبر. بعد الانتهاء تختفي تفاصيل الباقات وتعود أسعار الأجهزة الأصلية. الأسعار للباقات مع عدد العبوات المذكور؛ لم تُختلق نسب خصم مقارنة بسعر الجهاز وحده. حجم العبوات لم يُحدد، لذا لا يُذكر.

عدّل `assets/js/data/config.js` لتغيير الأسعار والتواريخ، و`offers.dates` في الترجمات الثلاث لتحديث النص الظاهر للمدة.

## الاستضافة

انشر `index.html` مع مجلد `assets` واحتفظ بملف `CNAME`. لا ترفع index.html وحده. مسارات المنتجات `#product/...` محفوظة. ملفات scripts وtests وdocs للصيانة.

نموذج التواصل يفتح مسودة بريد. WhatsApp وBit يعتمدان على التطبيقات الخارجية، ولا يوجد خادم طلبات أو تأكيد دفع داخل الموقع.
