# Aromifystore

متجر أجهزة التعطير بالعربية والعبرية والإنجليزية، يعمل كموقع ثابت دون خطوة بناء.

## التشغيل والفحص

يتطلب Node.js حديثًا، دون تثبيت حزم إضافية:

```sh
npm start
npm test
```

افتح `http://127.0.0.1:4173`. يلزم خادم عند المعاينة لأن JavaScript يستخدم ES modules.

## الملفات

- `index.html`: هيكل الصفحة.
- `assets/css/`: التصميم والعرض على الهاتف والخطوط.
- `assets/js/app.js`: التنقل واللغات والبحث والمعارض والتواصل.
- `assets/js/data/catalog.js`: المنتجات والصور والروائح.
- `assets/js/data/translations.js`: نصوص اللغات الثلاث والأسئلة الشائعة.
- `assets/js/data/config.js`: التواصل ومواعيد العروض وأسعار الباقات.
- `assets/js/offers.js`: منطق تفعيل العروض وانتهائها.
- `assets/images/products/`: صور المنتجات بأسماء وصفية.
- `assets/images/reference/`: صور موديلات إضافية تحتاج تأكيد هويتها.
- `assets/images/brand/`: الشعار الأصلي.
- `docs/image-map.json`: خريطة أسماء الصور الأصلية والجديدة.
- `docs/review.md`: التحقق والمعلومات التي تحتاج استكمالًا.

الصور بأسمائها الأصلية في جذر المستودع محفوظة أيضًا لضمان استمرار الروابط القديمة.

## تعديل العروض

تعرض `offers.html` و`offers-ar.html` و`offers-en.html` الباقات التسع. الأسعار وعدد عبوات العطر وشروط التوصيل والكفالة المحددة لكل عرض موجودة في `assets/js/data/config.js`. لم يحدد موعد انتهاء للباقات الحالية. لتحديد مدة لاحقًا، استخدم `startsAt` و`endsAt` مع توقيت إسرائيل. وقت الانتهاء غير مشمول، وبعده تعود أسعار المنتجات الأصلية. أعِد توليد صفحات المتجر بعد تعديل إعدادات الباقات الثابتة.

## الاستضافة

انشر `index.html` مع مجلد `assets` واحتفظ بملف `CNAME`. لا ترفع index.html وحده. مسارات المنتجات `#product/...` محفوظة. ملفات scripts وtests وdocs للصيانة.

نموذج التواصل يفتح مسودة بريد. WhatsApp وBit يعتمدان على التطبيقات الخارجية، ولا يوجد خادم طلبات أو تأكيد دفع داخل الموقع.

## السلة وإدارة المتجر

السلة على `cart.html` تدعم اللغات الثلاث وتحفظ المنتجات والكميات على جهاز الزائر. إرسال الطلب يفتح رسالة واتساب يرسلها الزائر بنفسه. يؤكد المتجر الطلب وتكلفة التوصيل ويعالج الدفع بالطريقة الحالية.

تشغيل التحقق من أكواد الخصم والأسعار يحتاج إلى [خدمة المتجر](checkout-api/README.md). بعد نشر الخدمة، اضبط عنوانها العام في `assets/js/store-runtime.js`. حينها يمكن لصاحب المتجر تسجيل الدخول عبر `admin.html` وإدارة الأكواد والأسعار وإنشاء حسابات مشرفين. صلاحية إنشاء الأكواد والحسابات تبقى لصاحب المتجر. لا تضع كلمات المرور أو مفاتيح الخدمة في هذا المستودع.


## صفحات البحث واللغات

أضيفت صفحات HTML جاهزة للفهرسة لكل لغة، وروابط canonical وhreflang وبيانات النشاط وrobots.txt وsitemap.xml. الروابط القديمة محفوظة. ملفات HTML الجديدة ناتجة عن البناء ولا تعدّل منفردة.

لتحديث الصفحات بعد تغيير النصوص أو المنتجات أو العروض: ثبّت حزم التطوير بـ `npm install` ثم شغّل `npm run build:seo` من جذر المستودع، وانشر الصفحات المولدة مع ملفات assets. القالب في scripts/seo-template.html، والبرنامج التفاعلي الجديد في assets/js/seo-app.js. البرنامج القديم app.js محفوظ للتوافق مع النسخ المخزنة مؤقتًا.

لا تتضمن البيانات المنظمة تقييمات أو مواعيد عمل أو وعود توفر غير مؤكدة. تحسين الفهرسة لا يضمن ترتيبًا محددًا في Google. لا تحذف وسم أو ملف التحقق من ملكية Search Console.
